# Download the PDFs

These are the **23 PDFs** in this collection. Select a title to download the named file directly from `main`. No preview server, script or topic ZIP is required. [Download the whole repository as one ZIP](https://github.com/officialliterallyspeaking-oss/otherworks/archive/refs/heads/main.zip) to get them all; open `research/pdfs/` inside it.
